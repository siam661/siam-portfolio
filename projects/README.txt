Drop project screenshots here, e.g.:
  urban-plate.jpg
  lumora-resort.jpg
  your-new-project.jpg

Then reference them in src/data/projects.js as:
  image: "/projects/urban-plate.jpg"

Recommended: 1600x1000px (or similar 16:10 ratio), JPG or WebP, under ~300KB each.
If a file is missing or fails to load, the site automatically falls back to a
clean numbered placeholder -- nothing breaks.
